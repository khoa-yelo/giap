## Panels (double width, 2 × 3 grid; the sixth cell holds the warning list)

- **(a) Preflight summary:** bar of check counts by level (`ok`, `info`, `warn`, `error`); the
  sixth cell lists the `warn` and `error` messages (`rule_id: message`), truncated to 10 lines with
  "+ n more".
- **(b) Contig lengths:** one horizontal bar per replicon (FASTA order), log₁₀ bp axis "length (bp)",
  bar colour by `kind` (chromosome `#0072B2`, plasmid `#009E73` — the §10.1 plasmid colour —,
  unknown `#999999`), a marker for `topology = circular`, and a dashed line at
  `preflight.min_largest_contig_warn` labelled with the rule.
- **(c) Peptide length distribution:** integer-bin histogram of distinct peptide sequences that
  reached mapping: `peptide_hits.peptide` (distinct) stacked over `unmapped` rows with
  `kind = peptide` (`sequence`); colours placed `#0072B2`, unmapped `#BBBBBB`; dotted lines at the
  `input.peptide_len` bounds; x "length (aa)".
- **(d) Abundance distribution:** histogram (40 equal bins over the observed range) of
  `abundance_log2` for genes with `abundance_imputed = false`, with the imputed genes as a separate
  stacked layer in `#E69F00`; x "log2 abundance"; absent when `abundance_type = none` for every gene.
- **(e) Missingness:** horizontal bars, share of NA per column among genes with `partial = false`,
  for `abundance_raw` and the feature columns of `genes.tsv` grouped as §9.3 groups them
  (promoters and transcription, translation initiation, codon usage, protein); one bar per column,
  sorted by group then column; x "missing (%)".

## Data TSV `plots/data/V17_qc.tsv`

Long format: `panel` enum{a, b, c, d, e}, `group`, `key`, `value`, `n`. Rows sorted by panel, group,
key. (a): `group = level`, `key` = level, `value` = count; warning messages as `group = message`,
`key = rule_id`, `value` NA. (b): `key = contig`, `value = length`, `group = kind`. (c): `key` =
length, `group` ∈ {placed, unmapped}, `value` = count. (d): `key` = bin left edge, `group` ∈
{measured, imputed}. (e): `group` = §9.3 group, `key` = column, `value` = share, `n` = genes.

## Title

"`<n_warn>` preflight warnings, `<n_error>` errors; `<x> %` of genes have a measured abundance".
With no abundance: "`<n_warn>` preflight warnings; no abundance input". (Counts only; no claim.)

## Degenerate cases

| Situation | Behaviour |
|---|---|
| no `genes_tsv` (pipeline stopped early, or `gippa report` on a partial `OUT/`) | panels (d), (e) "not available" |
| no peptides (protein-only run) | panel (c) "no peptide input" |
| every check `ok` | panel (a) one bar; warning cell "no warnings" |
| one contig | one bar |
| all abundance NA | panel (d) empty-state text; title uses "no abundance input" |
| > 20,000 distinct peptides | no change: panel (c) draws ≤ 34 bars (lengths 7–40) |

## Questions for the lead

   and `abundance_raw`, as above (it shows a missing layer at a glance, which complements
   `layer_missing`).
2. Peptide lengths: the normalised input (`peptides.norm.parquet`) is not in `OUT/`. **Proposed
   default:** distinct sequences that reached mapping (placed + unmapped), which is what §9.1
   publishes; peptides dropped by preflight (length < 7) are counted in panel (a)'s messages.
