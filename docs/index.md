# GIAP

GIAP (genome-integrated analysis of proteomics data) takes one assembled bacterial genome plus
proteomics evidence and asks what genome context explains about which proteins are detected, and
how abundant they are.

- [Get started](get-started/install.md): install GIAP, set up the databases and run the quickstart.
- [User guide](user-guide/inputs.md): inputs, running, outputs and how to read the results.
- [Reference](reference/cli.md): every command, configuration key, output table and flag, generated
  from the code and the schemas.
- [Methods](methods/index.md): one note per statistical method.
- [Decisions](adr/index.md): the architecture decision records.
