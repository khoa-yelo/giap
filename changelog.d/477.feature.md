Under `--profile docker`, Nextflow's tool containers no longer pull images at run time (`docker run --pull=never`), and preflight stops the run when a pinned image the selected modules need is not present locally, naming `gippa setup --images --profile docker`. It also reports a Docker client older than 20.10 (podman older than 3.0) and a Docker daemon that is not reachable. Docker 20.10 or later is required.
