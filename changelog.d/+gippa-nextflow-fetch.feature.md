`gippa setup` installs the official, checksum-pinned Nextflow 26.10.0 `-dist` launcher as `DIR/bin/nextflow` when no `nextflow` is on `PATH` (`--no-nextflow` skips it), with a per-item redirect allowlist; `gippa run` uses `nextflow` on `PATH`, else that launcher, and exits 2 when Java is missing or older than 17 (`gippa setup` only warns).
