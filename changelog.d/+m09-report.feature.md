Plots and report: every run writes 16 plots (SVG, PNG and PDF, each with its data as TSV) and a
self-contained, interactive `report.html` that works offline. `giap report` rebuilds the report from
a finished run directory, and `giap compare` compares two or more runs of one genome (detection
overlap, abundance agreement, stability) with its own plot and `compare.html`.
