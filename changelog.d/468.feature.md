`gippa run` now publishes the Bakta JSON and GBFF it produced as `OUT/annotation/tools/bakta/genome.json` and `genome.gbff` (copied, untouched), so `gippa makedb --annotation OUT/annotation/tools/bakta/genome.json` works after a run without running Bakta by hand. A precomputed Bakta JSON is not copied into `OUT/`.
