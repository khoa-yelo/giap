`gippa setup`: an error renaming a verified download into place (EXDEV, ESTALE or EIO on NFS) now
fails that item with a message naming its path, exit 2, and the remaining items still install,
instead of aborting with exit 5 and no `db_manifest.json`. A directory database is swapped by
renaming the old copy aside first, so a failed swap keeps the old copy.
