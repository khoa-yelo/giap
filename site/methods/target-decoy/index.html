    Target–decoy q-values and picked FDR¶

    Implements giap.stats.tda.{monotone_q, tda_qvalues, picked_fdr} (GIAP_SPEC.md §7.2.5, §7.3.2, §8.3, Appendix B.6; issue M4-01). Used by placement FDR (M3-10, per stratum) and the decoy_picked gene-detection tier (M4-11/12).

    Conventions¶

    • Higher score = better. Callers with "lower is better" statistics pass the negation (placement passes −E).
    • NaN and −inf mean absent (no evidence). +inf is a legal, best-possible score (e.g. a rank transform of q = 0).
    • Thresholds are the distinct observed target scores. At threshold t, T(t) and D(t) count every target and decoy with score ≥ t. A decoy tied with a target is therefore counted against it (the conservative reading, and consistent with "ties go to the decoy" in picking).
    • Output is one value per input target, in input order. Tied targets get equal q.

    Separate search: tda_qvalues(target, decoy, pi=1, plus_one=True)¶

    FDR(t) = π · (D(t) + 1) / T(t)        (π · D(t)/T(t) if plus_one=False)
qᵢ     = min_{t ≤ sᵢ} FDR(t), clipped to [0, 1]

    monotone_q does the second step: given FDR at thresholds sorted strictest → loosest, it returns the running minimum from the loose end. So a target's q is the smallest FDR among all thresholds that would still accept it, and accepting q ≤ α is the same as taking the loosest threshold with FDR ≤ α.

    • The +1. It is the "knockoff+" correction (Barber & Candès 2015; He et al. 2015): it stops D(t) = 0 from producing FDR = 0 when few targets pass. It makes small strata conservative by design: with no decoys at all, q = 1/T, so a stratum needs T ≥ 100 targets above the first decoy to accept anything at 0.01 (B.6: 150 targets → q = 0.0067 accepted; 50 targets → q = 0.02, none accepted).
    • π. π ∈ (0, 1] scales the decoy count to the expected share of wrong targets (π̂_wrong in §7.2.5; 1 for m ≥ 1 strata). π outside (0, 1] (or NaN) raises ValueError. π = 1 is always conservative when there are as many decoys as targets; π < 1 is valid only if π is a conservative (upward-biased) estimate of the true wrong share — see the violation table below.
    • Assumption. Decoys must be a sample from the null-target score distribution with the same number of draws as targets (one decoy search per target search). Separate search has no finite-sample guarantee; the guarantee is asymptotic plus the +1 margin, and the simulations below show it at level.

    Picked competition: picked_fdr(target_best, decoy_best)¶

    Savitski et al. (2015), applied to genes (§7.3.2). Per gene g, with target score s_g and paired decoy score s̃_g:

    1. Pick. The decoy wins when s̃_g ≥ s_g (a tie counts as a decoy) or when the gene has only decoy evidence. The target wins when s_g > s̃_g or the gene has only target evidence. A gene with neither is in no list.
    2. FDR and q. q over the picked list = tda_qvalues(picked targets, picked decoys) with π = 1 and +1: FDR(t) = (#picked decoys ≥ t + 1)/#picked targets ≥ t, made monotone.
    3. Output. q is defined only for target winners; it is NaN where the decoy wins or neither exists (the gene is then not_detected, decided in M4-12). decoy_wins is true also for decoy-only genes; n_target_wins, n_decoy_wins are reported counts.

    Why this controls FDR: for a null gene whose target and decoy scores are exchangeable, the picked label is a fair coin independent of the picked score, so picking is target–decoy competition and the (D + 1)/T rule with the loosest passing threshold is the knockoff+ procedure, which controls FDR in finite samples. A tie is a case where the coin cannot be read; giving it to the decoy keeps the coin at most fair for targets. Decoy-only genes count as decoys, which only lowers T/D and is conservative.

    What is and is not controlled¶

    Controlled (given the assumptions): the expected share of false entries among targets accepted at q ≤ α — placement FDR within a stratum, gene FDR within the picked list.

    Not controlled:

    • FDR for anything aggregated afterwards (genes from peptide q, operons from gene q, §8.7).
    • FDR when the decoys do not mimic null targets (wrong score distribution, missing decoys, different multiplicity). These are input-contract violations; the engine cannot detect them.
    • FWER: one false call at q ≤ 0.01 is expected about once per 100 calls.
    • Per-gene error: q is a set-level quantity; a gene with q = 0.009 is not "99.1 % certain".

    Six-frame ORF decoys in the simulator and the class q floor (M7-12, M7-11)¶

    The novel_orf_power scenario writes the decoys a search against giap makedb --six-frame-orfs would give. Each null PSM of a six-frame wrong peptide goes to its target row or to the rev_GIAPORF_… decoy of its makedb entry with probability ½ (stream [seed, 8]). The decoy keeps the null score, and its q and PEP come from the same score function (M7-12 decisions 21, 24). Statistician round 3 (PR #225, tests/calibration/attacks/test_attack_m7_sixframe_picked.py) found:

    • The picked label is a fair coin. The coin is drawn independently of the score, so the side that holds an entry's best PSM is fair. Pooled over 27 replicates at 1 Mb, 5575 of 10955 wrong peptides had their best PSM on the target side (0.509, binomial p = 0.064). The q and PEP are one monotone function of the score for targets and decoys alike, so ranking by q and then by score keeps the exchangeability. Under M7-11 rule 2 the procedure is therefore knockoff+.
    • Oracle class FDP is at level. The oracle picks at entry level, within each class, with no GIAP novel code. With 200 ORFs planted per class at 1 Mb, over 15 replicates:
    Class q = 0.01 q = 0.05 q = 0.10
    intergenic 0.0095 ± 0.0036 0.049 ± 0.008 0.107 ± 0.010
    cds_outframe 0.0063 ± 0.0021 0.044 ± 0.004 0.105 ± 0.008
    antisense 0.0033 ± 0.0016 0.048 ± 0.007 0.096 ± 0.010
    • The q and PEP on target rows are about 2× conservative. The mixture uses the pre-coin wrong share. After the coin, only half of the null PSMs remain targets. At 1 Mb, target PSMs at q ≤ 0.01 have FDP 0.005, and the sum of PEP is 869 against 608 wrong target rows. A real engine estimates q from the decoys, so its target q is not inflated in this way. Nothing in the picked class FDR reads q or PEP as a probability. Any calibration check of PSM-level q or PEP on this scenario must use the post-coin share instead.
    • Class q floor. (D + 1)/T can never fall below 1/T, so a class with fewer than 1/α = 100 target ORFs calls nothing at α = 0.01. This is not specific to the simulator. In a real genome, the picked class FDR at 0.01 calls nothing in a class with fewer than about 100 detected candidates (M7-11 example 2). The scenario defaults plant 16 per class at 300 kb and 40 at 1 Mb. At those sizes the oracle's minimum class q is 0.056–0.077 at 300 kb (3 seeds) and 0.025–0.028 at 1 Mb (12 seeds), with 0 calls at 0.01 in every replicate. G3 (F1 ≥ 0.9 of called ORFs) is then 0 by construction. At 1 Mb, intergenic planting stops at about 100–145 ORFs (gap supply), whatever the requested count.

    Scored null decoys on the real K-12 genome (MVP-04, PR #247)¶

    decoys = "scored_null" (giapsim, MVP-04 step 6) models a DIA-NN --report-decoys search against giap makedb --six-frame-orfs. Every null PSM row goes to its target or to its entry's decoy on an independent ½ coin (stream [seed, 8]; scores come from stream [seed, 3]). The decoy keeps the row's score, q and PEP. Protein-entry nulls are real tryptic products of loci with no true peptide, with the locus drawn uniformly (lead decision 9). Statistician review of PR #247 (Slurm 1871592: K-12, 10 seeds; 1871626: attack file):

    • Why the coin gives the picked gene FDR its null. A null gene's PSMs are i.i.d. and their coins are independent of the scores. The side that holds the gene's best row is therefore a fair coin, independent of the picked score, and (D + 1)/T is knockoff+ on the null genes. Targets and decoys carry the same key columns, so the M4-24 shared key is S = {q, pep, score} and there is no decoy_unscored. q and PEP are one monotone function of the score on both sides. The mixture q is at most π_wrong_realised ≈ 0.01, so at π_wrong = 0.01 the ADR-0047 decoy filter removes almost nothing, and what it removes is symmetric. Collisions: 0 in 10 seeds.
    • Why match_wrong decoys are off. They are reversed random proteins that no null target matches. On a true gene they can only take a win from it; on a gene with no target they are a decoy-only win. Either way D grows with no null target behind it, which mixes a conservative bias into the null being measured.
    • The 1/T floor. T ≈ 2,700 target-won genes (b0 −5.25; truth-detected share 0.631), so q_floor ≈ 0.00037 ≪ 0.01. The floor is not what limits the run.
    • The gene-level null is too sparse for the α = 0.01 gates under the search-space split. Protein entries are 12.5 % of the distinct tryptic products, which leaves about 21 protein-entry nulls per run (mean 20.7, range 20–22), about 11 decoy wins (7–15) and about 10 false target-won genes, against T ≈ 2,700.
    • (D + 1)/T at the loosest threshold is 0.004, so the α cut never binds: n_detected = T on 10 of 10 seeds. Realised gene FDP is 0.0037 ± 0.0004.
    • An engine that ignores the decoys would reach only FDP ≈ 0.0076 (0.0073–0.0082), which is below α and below gate 7 (0.02). Gate 7 therefore cannot fail.
    • With the Q2 alternative (a fixed 50/50 split) there are about 83 protein nulls and about 41 decoy wins. The cut binds on 10 of 10 seeds, mean FDP at α = 0.01 is 0.0104 ± 0.0013, and an engine that ignores the decoys reaches 0.029–0.032, so gate 7 can fail.
    • π_wrong 0.03 or 0.05 under the search-space split still leaves the decoy-blind FDP below 0.02.
    • The Q2 fallback (50/50 when there are fewer than 50 gene-level null PSMs) is not monotone. On the 200-kb excerpt, π_wrong 0.05 gives 47 protein nulls (50/50), while π_wrong 0.10 gives 26 (search space).
    • A second gene-level channel. Six-frame nulls on GIAPORF_nterm_extension_* entries place in a gene's nterm_extension class, which assigns to the gene (about 11 undetected genes per K-12 run, next to the ~21 protein nulls). Their rev_GIAPORF_* decoys pair with the gene only when a target row of the entry was accepted, so that the entry is voted to the gene (M7-12 decision 28). If every row went to the decoy side, the gene vanishes instead of being a decoy win. With k rows, P(target wins | the gene is seen) = ½ / (1 − 2^−k), which is 4/7 for k = 3: anti-conservative, and small at K-12 (≈ +0.8 false genes against D ≈ 11).
    • Dense-null attack (tests/calibration/attacks/test_attack_mvp04_scored_null.py). This is the 200-kb excerpt at π_wrong 0.05 with the 50/50 split, and it includes the nterm channel. Mean gene FDP at q = 0.01 / 0.05 / 0.10 is 0.0092 / 0.0517 / 0.0915 at R = 50, and 0.0087 / 0.0463 / 0.0866 at R = 300. All pass. A decoy-blind engine is a confirmed failure at 0.01 and 0.05. Two slow tests ("gate 7 can fail", "the α cut binds") check the K-12 run; they were strict xfails under the search-space split.

    What the evidence run uses (MVP-04 lead decisions 10–16; statistician re-check, Slurm 1872374)¶

    • Fixed 50/50 split (decision 10): half the null peptides, rounded down, go to protein entries, capped by the pool. The search-space share (0.125) is recorded for information only. The pool also holds the loci that the sample strain makes pseudo through a premature stop (decision 16). GIAP sees them as intact, eligible genes. Products that span the stop are skipped. No protein null lands on a recorded pseudo or truncated locus.
    • K-12, seeds 1–10, oracle with the nterm-extension and multi_identical channels:
    • 80–89 protein nulls per run and 81–95 genes with null evidence. Collisions: 0.
    • D = 42.5 ± 1.9 (36–54); T ≈ 2,740.
    • The α = 0.01 cut binds on 10 of 10 seeds.
    • Mean gene FDP at α 0.01 is 0.0109 ± 0.0013 (0.0051–0.0183), at level against q + 2 SE = 0.0126.
    • A decoy-blind engine gives 0.0262 ± 0.0006 (0.0233–0.0287), above gate 7's 0.02.
    • False detected genes come mostly from protein nulls; the nterm channel adds 0–6 per run.
    • At K12_EVIDENCE_SEED: T 2,744, 2,721 detected, FDP 0.0077, decoy-blind 0.0284, which matches Slurm 1872190.
    • Gate 7 catches only gross failures. Per seed, a correct engine has FDP sd ≈ 0.004 and a maximum of 0.018 over 10 seeds. A decoy-blind engine is only 1.2–1.4 × the gate. An engine that inflates FDR by 1.5× (mean ≈ 0.016) would usually still pass. The calibration suites and the dense-null attack own the mean; gate 7 is a single-run check of the gross picture. With one fixed seed the result is deterministic, so this is a power limit, not flakiness.
    • Recorded deviation (decision 13): decision 9 draws the protein-null locus uniformly. The §8.4 gene-FDR generator draws size-proportionally. Picked validity does not depend on it, because each null gene is exchangeable either way. A MAYU-tier check on these inputs would see a different null from its calibration suite.

    Convergent and sandwich decoys (operons, M6-01)¶

    giap.stats.decoy_fdr reuses monotone_q for the missed-operon family (§7.4.4); the full method and its power analysis are in docs/methods/operons.md. What differs from the separate search above:

    • Decoys are not one per target. CV (convergent) and SW (→ ← →) pairs are whatever the genome has, in different numbers and with a different intergenic-distance mix than the NO targets. The "one decoy per target, same distribution" assumption of tda_qvalues is replaced by within-bin exchangeability: in each distance bin b, |Δ| of a null NO pair and of a decoy have the same distribution. Each bin's decoy tail fraction (D_b + 1)/(N_decoy,b + 1) is scaled by the bin's target count N_NO,b, so the decoys are reweighted to the targets' distance mix and their number no longer matters.
    • The +1 is per bin, so the small-list floor is ≈ π₀ Σ_b N_NO,b/(N_decoy,b + 1) phantom false targets — about B times the single-bin floor, dominated by the bin with the fewest decoys per target. A bin with targets and no decoys contributes all its targets.
    • Two decoy sets, the larger FDR wins, maximum taken before monotonising. CV partners can be less alike than same-strand neighbours (transcriptional interference), which is conservative; SW pairs are farther apart. Reporting the larger guards against whichever set happens to mimic null NO pairs badly in the conservative direction; it does not guard against a set that is more alike than null targets (anti-conservative), which only an attack null can reveal.
    • π₀ = 1 and N_NO,b counts every target, so the estimate is conservative by ≈ π₀.

    At NOVEL_PER_CLASS_GATE = 300 the intergenic class is limited by gap supply: 88–122 ORFs have a true peptide over seeds 1–8 at 1M, so in about 3 of 8 replicates it stays above the class q floor at α = 0.01. The other three classes clear it on every seed (M7-12 lead decision 28).

    Consequence for real genomes¶

    The same floor applies outside the simulator. At α = 0.01 the picked class FDR calls nothing in a novel-ORF class with fewer than about 100 target candidates, because q ≥ 1/T. A small class is then reported with zero calls; this is not evidence that it has no novel ORFs. The report states this (M7-13), and M7-12 gates use NOVEL_PER_CLASS_GATE = 300 at 1M (M7-12 lead decision 26).

    Numerical notes¶

    • Counts use searchsorted on sorted arrays (O(n log n)); no floating-point equality beyond the exact ≥ comparison of the caller's scores. Callers that compute scores on different paths for targets and decoys must round consistently, or a near-tie becomes a target win.
    • monotone_q assumes no NaN in its input (a NaN propagates to all stricter thresholds); the public functions never pass one.
