    GIAP preprint outline (M11-11)¶

    An outline, not a draft (docs/specs/M11-11-preprint-outline.md): headings, one-line intents, the figure and table plan, and a claim → evidence map. No result appears here that is not in a committed evidence file; every other number is TBD and its row is pending, naming the issue that will produce it. Kept in the repository and left out of the site navigation (Q-L6 style). Aggregates only (Khoa's 2026-10-24 pilot data rule): no peptide sequences, no DIA-NN rows.

    Rule for the paper (R3). The text may claim only what the gates and the readiness table (validation/release/1.0.0/readiness.json, M11-03 and M11-13) say. A gate that is waived, vacuous, deferred or pending is reported as such, never as a pass. A threshold is never restated more loosely than ci/gates.yaml or tests/calibration/tolerances.yaml define it.

    2. Sections (intent only)¶

    1. Abstract (structure only): problem; what GIAP does (one gene table keyed by Bakta locus tags); how errors are controlled; what the Nissle 1917 pilot showed; availability. Numbers only from rows marked supported in §4 at submission time.
    2. Introduction. The question: how much of what a bacterial proteome detects, and how much it holds, is explained by genome context (operons, islands, mobile elements, codon usage, promoters), and how to ask that without the database mismatch of a generic reference.
    3. Design. Inputs (genome, Bakta annotation, peptide or protein tables from any search engine); one gene table keyed by Bakta locus tags; the modules (annotation layers, mapping, gene table and detectability, region tests, autocorrelation and islands, operons, variants, novel ORFs, function, determinants, report, compare). Tools run as separate programs (§5 below).
    4. Error control. One paragraph per family with its estimand and its null, each pointing at its methods note: placement FDR (docs/methods/placement-fdr.md), gene-level FDR, picked and MAYU (docs/methods/detection-tiers.md, docs/methods/mayu-gene-fdr.md), circular-shift region tests (docs/methods/region-tests.md, docs/methods/permutation-and-shifts.md), island FWER (docs/methods/islands.md), operon decoys (docs/methods/operons.md), BH families (docs/methods/multiple-testing.md), the attack nulls and the calibration harness (docs/methods/calibration.md).
    5. Validation. (a) Simulation calibration with the giapsim simulator (the four one-sided criteria of docs/methods/calibration.md); (b) the Nissle 1917 pilot with arms A1 (generic K-12 reference), A2 (matched strain) and A3 (de novo); (c) the true-example assertions TE1–TE8 (GIAP_SPEC.md §11.6).
    6. Performance. Measured wall time and peak memory on FarmShare for the standard run on 16 threads and 64 GB, with the node class; per-tool runtimes.
    7. Availability. PyPI and Bioconda packages, containers pinned by digest, Zenodo DOI, the documentation site, licences (§5 below).
    8. Limitations. What version 1 defers (§6 below), stated before the reader has to ask.

    5. Data, code and licence availability¶

    • [ ] Proteomics data: PXD078459 (iProX, Nissle 1917, three wild-type runs), cited by accession; never redistributed by GIAP. Only aggregates and file checksums are committed (validation/pilot/inputs/pxd078459_files.tsv).
    • [ ] Genomes and proteomes: Nissle 1917 GCA_043228065.1; K-12 MG1655 GCA_000005845.2; UniProt K-12 proteome UP000000625 (A1's database). Later work: UTI89 GCA_000013265.1 / PXD053727.
    • [ ] Not redistributed, and why: RegulonDB (its terms; fetched by validation/fetch_regulondb.py, never committed); DIA-NN output rows (Khoa's pilot data rule); DIA-NN itself (proprietary academic licence; the version used is 2.3.1 Academia, not the spec's 2.7.0, docs/adr/ADR-0051-diann-version.md, proposed); the Cascadia checkpoint and vendor SDKs (docs/adr/ADR-0054-a3-external-artefacts.md).
    • [ ] Code: GIAP is MIT-licensed; PyPI and Bioconda packages (TBD, M11-04, M11-10); Zenodo DOI (TBD, M11-13); documentation URL (TBD, M11-07, Q-K9); containers by digest (workflow/conf/containers.config, M11-06).
    • [ ] Third-party licences (NOTICE.md, docs/adr/ADR-0008-tool-pins.md), to be stated in the paper:
    • GPL-3.0 tools (Bakta, Promotech, Promoter Calculator, OSTIR, TransTermHP, BacTermFinder) and AGPL-3.0 antiSMASH run as separate programs; GIAP never imports them (scripts/ci/check_imports.py). R and fgsea run as a separate process (ADR-0038).
    • geNOMAD is licensed for non-commercial use only; a commercial user must drop the module or obtain a licence.
    • KEGG is for academic use; non-academic users need a KEGG licence or the GO and COG collections only.
    • UniOP has no licence file: fetched at a pinned commit, never vendored or pushed as an image.
    • DIA-NN is proprietary (academic licence) and used only for users' own searches.

    6. Limitations (what version 1 defers, GIAP_SPEC.md §16)¶

    • Single sample per run: no co-expression or differential context tests across samples.
    • Full validation not done: K-12 PXD075568, UTI89 beyond the A3 fallback, FDRBench entrapment, and the K-12 co-abundance AUROC (§13.2 b7). Release 1.0 is calibrated on simulations and one light pilot.
    • Sealed holdout not used: the EDL933 holdout (PXD068911, §14.5) stays sealed for the full validation; no holdout claim is made.
    • A3 de novo arm is exploratory; its feasibility check covers WT_1 only (C21).
    • Deferred modules: assembly checks from frameshift-spanning peptides, CheckM2 in preflight, proteome mass fractions and the V9 treemap, RO-Crate export, H-NS GC test, prophage induction, RNA-seq and Ribo-seq inputs, the V4 locus browser, taxonomy of unmapped sequences, homology evidence for novel ORFs (changelog.d/+known-limitations.misc.md).
    • Out of scope by design (§16 "No"): the recoding and start catalogue (Sec, prfB +1, dnaX −1, non-ATG starts, Met removal), start-codon correction from N-terminal peptides, signal-peptide or transmembrane prediction, PTM naming or classification, Plass, eggNOG-mapper and MMseqs2/UniRef function annotation, and spectrum searching (GIAP only writes the makedb FASTA). The paper must not imply any of them.

    Statistical caveats a reader must apply (each recorded in a cited note):

    • ORA p-values are uncalibrated: every ORA row carries ora_uncalibrated (docs/methods/function.md › Pass-1 limit (decision 13; ADR-0035 decision 3)).
    • Gate M7 is not passed: variant F1 0.838 < 0.9 (docs/adr/ADR-0049-m7-variant-precision.md).
    • Operons: the missed-operon family is near-powerless and vacuous with the shipped decoys; discordance level is claimed only under smooth, monotone σ(abundance) (docs/adr/ADR-0055-operon-discordance-abundance-noise.md).
    • GSEA restricted claim: no level claim for genomically clustered sets; results are conditional on detection; BH spillover from flagged rows is not re-measured on the R engine (docs/adr/ADR-0025-gsea-clustered-sets.md, docs/adr/ADR-0026-gsea-conditional-on-detection.md).
    • Islands outside the validity domain: the FWER is breached at ρ = 0.9 with short ℓ′, and the low direction is a structural zero, so a null result is not evidence of no silenced island (docs/methods/islands.md).
    • Region tests: the HL shift is relative to random positions on this replicon; the ori → ter dosage gradient is not modelled in giapsim (docs/methods/region-tests.md › Limitations (statistician)).
    • Genome decoys under-count chance hits of protein-like wrong peptides (D/T 0.96 at realistic dipeptide structure; docs/methods/placement-fdr.md › Limitations (documented, not CI gates)); the real-protein TE8 check is still owed.
    • Determinants: the permutation p-value ships flagged null_uncalibrated; it fails the §8.5 dependence attacks (C18, docs/adr/ADR-0034-determinants-null-uncalibrated.md).
    • K-12 calibration: the TerminatorNet precision against RegulonDB is a lower bound, and the UniOP AUROC is a K-12 number whose in-sample status is unverified (UniOP's training data are not verified), not a transfer claim (docs/adr/ADR-0022-uniop-terminatornet-cutoffs.md).
    • P(miss) is a probability, not a p-value, and sits outside the BH family (docs/adr/ADR-0056-pmiss-outside-the-bh-family.md).
