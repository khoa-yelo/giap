    Licences¶

    GIAP itself is MIT-licensed. The tools and databases it uses keep their own licences. Some of these restrict who may use them. Read this page before you install the databases or publish results.

    What you need to know¶

    • geNOMAD is for non-commercial use only. geNOMAD (module mobile) is licensed for non-commercial use. For commercial use, switch the module off: run with --modules core,bgc,function, and install with giap setup --no-genomad.
    • KEGG is free for academic use only. giap setup --kegg downloads the KEGG KO-to-pathway links and pathway names from rest.kegg.jp. Academic users may use them freely. Other users need a licence from KEGG. Runs with the function module contain KEGG pathway names, and the manifest records the KEGG retrieval date.
    • GPL and AGPL tools run as separate programs. Bakta, Promotech, Promoter Calculator, OSTIR, TransTermHP and BacTermFinder (GPL-3.0), and antiSMASH (AGPL-3.0), each run in their own pinned container or Conda environment. GIAP calls them as separate processes and never imports or vendors their code. A CI check (scripts/ci/check_imports.py) guards this. R and the fgsea runner run the same way (ADR-0038).
    • UniOP has no licence. UniOP's repository has no licence file. GIAP fetches it from its upstream repository at a pinned commit (3ed14dfc) when the tool environments are built. GIAP never redistributes it, and no UniOP container image is published.
    • DIA-NN is proprietary. DIA-NN is used only for your own searches, under your own DIA-NN licence (NOTICE.md: "proprietary (academic licence)"). GIAP never redistributes DIA-NN binaries, and giap convert --from diann reads only its report files.
    • RegulonDB is not redistributed. GIAP's developers use RegulonDB only to calibrate cut-offs. giap setup does not download it.
    • The contaminant library has no licence file. The universal protein contaminant FASTA (Frankenfield et al. 2022) is therefore downloaded by giap setup --contaminants at a pinned commit and never vendored.

    Container images: .github/workflows/containers.yml builds five images for GHCR (ghcr.io/khoa-yelo/giap-<tool>: promotech, promoter_calculator, terminatornet, bactermfinder, ostir). Their digests enter workflow/conf/containers.config only through the digest-pin PR that the workflow opens; until that PR merges, these tools run from their Conda environments. Four of them contain GPL-3.0 tools fetched from upstream at build time, unmodified: Promotech (https://github.com/BioinformaticsLabAtMUN/PromoTech), Promoter Calculator (GPL-3.0-or-later, https://pypi.org/project/promotercalculator/1.2.4/), OSTIR (https://pypi.org/project/ostir/1.1.3/) and BacTermFinder (https://github.com/BioinformaticsLabAtMUN/BacTermFinder); the corresponding source is available at those links at the pinned versions and commits above, and each image's Dockerfile is in workflow/containers/<tool>/. TerminatorNet (MIT, https://github.com/btjaden/TerminatorNet) is the fifth. UniOP (unlicensed) is never published.

    Data resources: KEGG (academic use), RegulonDB (not redistributed), Gene Ontology (CC BY 4.0), NCBI COG 2020 (NCBI FTP).

    Contaminant library: the universal protein contaminant FASTA of Frankenfield et al. 2022 (HaoGroup-ProtContLib/Protein-Contaminant-Libraries-for-DDA-and-DIA-Proteomics, commit bddf6da9); no licence file found in the repository (checked 2026-10-15), so it is downloaded by giap setup --contaminants and never vendored (R11).
