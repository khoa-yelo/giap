    Output tables¶

    pileup¶

    One row per codon covered by an eligible peptide, with REF, I/L and ALT distinct-peptide counts (GIAP_SPEC.md §7.5.2, §7.5.5, §9.3).

    • Path: tables/pileup.tsv.gz
    • Coordinates: 1-based closed
    • Schema: tables/pileup.schema.json
    Field Type Unit Description Constraints
    contig string — Replicon name (C1 order) required
    codon_start integer — Lowest coordinate of the codon, 1-based, within [1, length] required; minimum 1
    strand string — Strand of the peptides' reading frame required; one of +, -
    gene string — Locus tag of the same-strand gene framing the codon (smallest tag if several) —
    aa_pos integer — 1-based residue position of the codon in the gene minimum 1
    ref_aa string — Table-11 reference residue of the codon on the strand required
    n_ref integer — Distinct peptides (I/L folded) reading the reference residue required; minimum 0
    n_il integer — Distinct peptides reading I or L at an I/L codon (ambiguous) required; minimum 0
    alt_counts string — Semicolon-joined ALT keys with their distinct-peptide counts (X:n;Y:m), most supported first pattern [^:;]+:[1-9][0-9]*(?:;[^:;]+:[1-9][0-9]*)*
    call string — Codon call required; one of REF, ALT, mixed, no_call

    variants¶

    Sites with an ALT or mixed call, plus frameshift events (GIAP_SPEC.md §7.5.2, §7.5.5, §9.3).

    • Path: tables/variants.tsv
    • Coordinates: 1-based closed
    • Schema: tables/variants.schema.json
    Field Type Unit Description Constraints
    variant_id string — Variant identifier, numbered from 1 in table order required; pattern VAR_[1-9][0-9]*
    contig string — Replicon name (C1 order) required
    codon_start integer — Lowest coordinate of the site's first codon in peptide order, 1-based, within [1, length] required; minimum 1
    strand string — Strand of the peptides' reading frame required; one of +, -
    gene string — Locus tag of the same-strand gene framing the codon —
    aa_pos integer — 1-based residue position of the codon in the gene minimum 1
    ref_codon string — Gene-strand bases of the codon(s) the REF allele spans (6 nt for two-codon events); for a frameshift, the last prefix codon required; pattern [ACGTN]+
    ref_aa string — Reference residue of the first codon required
    alt_aa string — ALT residue(s) (J = I or L); fs+1 or fs-1 for a frameshift required
    alt_type string — Kind of ALT required; one of substitution, swap, block, frameshift
    call string — Site call required; one of ALT, mixed
    confidence string — high: at least variants.high_min_peptides distinct ALT peptides required; one of high, candidate
    n_ref integer — Distinct REF peptides at the codon required; minimum 0
    n_alt integer — Distinct peptides supporting this ALT required; minimum 1
    nt_changes integer — Nucleotide changes of the minimal-change ALT codon(s) (G14); NA for unequal-length events minimum 0
    alt_codon_vcf string — Forward-strand ALT allele written to the VCF; NA when not in the VCF pattern [ACGTN]+
    class_error_rate string — Class-specific error rate (%.6g) or unestimated required; pattern unestimated|[0-9.eE+-]+
    class_error_n integer — Paired de novo observations (reads) pooled into the class error rate minimum 0
    source string — Semicolon-joined sources of the ALT peptides required; pattern (?:database|denovo)(?:;(?:database|denovo))*
    flags string — Semicolon-joined flags from the Variants vocabulary (§9.4) pattern (?:mass_equivalent|snv|multi_nt|strain_difference|database_derived|start_codon|stop_codon|vcf_unrepresentable)(?:;(?:mass_equivalent|snv|multi_nt|strain_difference|database_derived|start_codon|stop_codon|vcf_unrepresentable))*

    novel_orfs¶

    One row per novel ORF candidate (GIAP_SPEC.md §7.6.6, §9.3; ADR-0012 decision 3).

    • Path: tables/novel_orfs.tsv
    • Coordinates: 1-based closed
    • Schema: tables/novel_orfs.schema.json
    Field Type Unit Description Constraints
    orf_id string — Novel ORF ID NOVEL_<contig>_<lowest 1-based coordinate of the longest interval>_<p|m> required; pattern NOVEL_[A-Za-z0-9._-]+_[1-9][0-9]*_[pm]
    class string — Novel-ORF class (§7.6.1, ADR-0013) required; one of nterm_extension, cterm_extension, intergenic, cds_outframe, antisense, pseudogene, sorf
    contig string — Replicon ID required
    strand string — Strand required; one of +, -
    frame integer — Reading frame (+1..+3, -1..-3) —
    start_longest integer — 1-based position of the first base of the most upstream start codon, in transcription direction (on '-' the highest coordinate, so start > end there; unlike other tables, not the lowest/highest pair); NA without a start codon minimum 1
    start_best_ostir integer — 1-based position of the first base of the start codon with the best OSTIR score, in transcription direction (on '-' the highest coordinate, so start > end there; unlike other tables, not the lowest/highest pair); NA without an OSTIR score minimum 1
    end integer — 1-based position of the last base of the stop codon (of the last whole codon when open at a linear end), in transcription direction (on '-' the highest coordinate, so start > end there; unlike other tables, not the lowest/highest pair) required; minimum 1
    length_aa_longest integer — Protein length (aa, stop excluded) from start_longest, or from the first peptide without a start codon minimum 1
    length_aa_best integer — Protein length (aa, stop excluded) from start_best_ostir, or from start_longest when it is NA minimum 1
    start_codon_best string — Start codon at start_best_ostir (or start_longest when it is NA) —
    n_peptides integer — Distinct peptides (I/L folded) supporting the ORF required; minimum 0
    peptides string — Supporting peptides, I/L folded (';'-separated list) —
    best_peptide_q number — Lowest q-value of the supporting peptides —
    ostir_tir number — OSTIR translation initiation rate at start_best_ostir —
    promoter_score number — Best Promotech score upstream of the ORF (second round, M7-08) —
    promoter_supported boolean — A promoter supports the ORF (ADR-0012) —
    terminator_downstream boolean — A terminator lies downstream of the stop codon (ADR-0012) —
    terminator_conf number — Confidence of that terminator (ADR-0012) —
    terminator_distance_nt integer — Distance from the stop codon to that terminator, nt (ADR-0012) —
    rbs_supported boolean — The start has RBS support (OSTIR threshold) —
    class_fdr string — Class-level FDR as a float (%.6g), or 'unestimated' required; pattern unestimated|[0-9]+(?:\.[0-9]*)?(?:[eE][-+]?[0-9]+)?
    called boolean — The ORF is called (§7.6.4) required
    rank integer — Rank among novel ORFs (M7-09); not the row order minimum 1
    overlapping_gene string — Locus tag of the overlapped or extended gene —
    flags string — Semicolon-joined flags from the controlled vocabulary (§9.4); denovo_only_unsupported: every peptide is de novo, none is a database PSM, and there is no RBS support beyond the class rule (ADR-0050) pattern (?:junction_spanned|homopolymer_junction|class_fdr_unestimated|rbs_supported|no_start_codon|partial|ostir_missing|rbs_threshold_unestimated|junction_unknown|promoter_supported|terminator_supported|readthrough_candidate|denovo_only_unsupported)(?:;(?:junction_spanned|homopolymer_junction|class_fdr_unestimated|rbs_supported|no_start_codon|partial|ostir_missing|rbs_threshold_unestimated|junction_unknown|promoter_supported|terminator_supported|readthrough_candidate|denovo_only_unsupported))*

    replicon_landmarks¶

    Plot support table (ADR-0043): oriC and terminus of every replicon, for V1 and V2 (GIAP_SPEC.md §7.3.5(e), §10.2). Not a result table.

    • Path: plots/support/replicon_landmarks.tsv
    • Coordinates: 1-based closed
    • Schema: plot_support/replicon_landmarks.json
    Field Type Unit Description Constraints
    contig string — Replicon name (C1 = FASTA order) required
    length_bp integer — Replicon length in bp required; minimum 1
    topology string — Replicon topology required; one of circular, linear
    oric_position integer — 1-based oriC position (giap.context.oriter.oric_position); NA on linear and no_oric replicons minimum 1
    ter_position integer — 1-based terminus position, ((oriC0 + L // 2) mod L) + 1; NA with oric_position minimum 1
    status string — called, no_oric (no call or calls too far apart) or linear required; one of called, no_oric, linear

    gc_skew¶

    Plot support table (ADR-0043): windowed GC skew of every replicon, for V1 (GIAP_SPEC.md §10.2). Not a result table.

    • Path: plots/support/gc_skew.tsv
    • Coordinates: 1-based closed
    • Schema: plot_support/gc_skew.json
    Field Type Unit Description Constraints
    contig string — Replicon name (C1 = FASTA order) required
    start integer — 1-based first position of the window required; minimum 1
    end integer — 1-based last position of the window (closed); the last window of a contig is shorter required; minimum 1
    gc_skew number — (G - C) / (G + C) in the window; NA when G + C = 0 minimum -1; maximum 1
    cumulative_gc_skew number — Running sum of gc_skew from position 1 of the contig; an NA window adds 0 required

    gsea_running¶

    The fgsea running sum of the top 6 GSEA sets (smallest q_value, then largest |nes|, collection, term; p_value NA excluded), one row per ranked TU, for V14(a) (GIAP_SPEC.md §10.2; docs/specs/M9-17-plot-support-analysis.md). Written by the function step. Not a result table.

    • Path: plots/support/gsea_running.tsv
    • Coordinates: —
    • Schema: plot_support/gsea_running.json
    Field Type Unit Description Constraints
    collection string — Collection of the set (enrichment_gsea.tsv) required
    term string — Term ID of the set (enrichment_gsea.tsv) required
    rank_position integer — 1-based position of the TU in fgsea's ranking required; minimum 1
    tu_id string — Ranked TU required
    score number — The median-centred TU score fgsea ranked (ADR-0028); non-increasing in rank_position required
    in_set boolean — Whether the TU is a member of the set required
    running_es number — fgsea's running enrichment score after this position (scoreType std, gseaParam 1); its max deviation from 0 is the set's es required

    determinants_shap¶

    Per-feature LightGBM SHAP values (pred_contrib, mean over the out-of-fold boosters) of the model rows for the top 20 encoded model columns by mean |SHAP|, for V15(c) (GIAP_SPEC.md §10.2, §7.8.2; docs/specs/M9-17-plot-support-analysis.md). Summed by block over every column they equal determinants_attribution.tsv's shap_<block> columns. Written by the determinants step. Not a result table.

    • Path: plots/support/determinants_shap.tsv
    • Coordinates: —
    • Schema: plot_support/determinants_shap.json
    Field Type Unit Description Constraints
    locus_tag string — Model-row gene required
    feature string — Encoded model column (determinants model matrix) required
    feature_value number — Model-matrix value of the column for this gene (tir_ostir and length_aa on their ln scale); NA when missing —
    shap number — Mean over the out-of-fold boosters of the column's pred_contrib required

    determinants_pd¶

    LightGBM partial dependence of CAI, tAI, OSTIR TIR and promoter score, for V15(b) (GIAP_SPEC.md §10.2; docs/specs/M9-17-plot-support-analysis.md). Grid: the 5 %, 10 %, ..., 95 % quantiles plus min and max of the feature over the model rows, on the feature's own scale. Written by the determinants step. Not a result table.

    • Path: plots/support/determinants_pd.tsv
    • Coordinates: —
    • Schema: plot_support/determinants_pd.json
    Field Type Unit Description Constraints
    feature string — PD feature (determinants_features.tsv column) required; one of cai, tai, tir_ostir, promotech_max
    grid_value number — Grid value on the feature's own scale (tir_ostir is logged before predicting) required
    pd_mean number — Mean over boosters of each booster's mean prediction over the model rows with the feature set to grid_value required
    pd_low number — Minimum over boosters of the per-booster partial dependence: a spread over the boosters, not a confidence interval required
    pd_high number — Maximum over boosters of the per-booster partial dependence: a spread over the boosters, not a confidence interval required

    null_regions¶

    Circular-shift null of every tested region and statistic, for V18 (GIAP_SPEC.md §7.3.5(b), §10.2; docs/specs/M9-17-plot-support-analysis.md). The values are the statistic each test compares: for o_minus_e the ADR-0018 studentised sum(d - p) / sqrt(sum p (1 - p)), for hl_shift the studentised T = HL / sqrt(V) of ADR-0018's amendments, not the reported effect. Written by the context_stats step while the file stays under 5 MB (2^20 bytes per MB); otherwise the file holds the 1st-99th percentile grid of each null and its header's fourth column is percentile (1-99) instead of shift_k (schema plot_support/null_regions_grid.json). Not a result table.

    • Path: plots/support/null_regions.tsv
    • Coordinates: —
    • Schema: plot_support/null_regions.json
    Field Type Unit Description Constraints
    region_id string — Region (regions_stats.tsv) required
    contig string — Replicon the region was tested on (a region split across contigs has one null per contig) required
    stat string — Test statistic of the region test required; one of o_minus_e, hl_shift
    shift_k integer — Circular gene-index shift k of the null draw (percentile 1-99 in the percentile-grid form of the file) required; minimum 1
    null_value number — The studentised statistic at this shift (or the null's percentile in the grid form); NA when undefined —
    observed number — The observed studentised statistic the null is compared with required

Written by the context_stats step. Not a result table.

    • Path: plots/support/null_islands.tsv
    • Coordinates: —
    • Schema: plot_support/null_islands.json
    Field Type Unit Description Constraints
    contig string — Scanned replicon (C1 order) required
    direction string — Which tail the maximum is over: abs (|S_w|, the scan is two-sided) required; one of abs
    replicate integer — Bootstrap replicate, 1..B required; minimum 1
    max_scan_s number — Maximum |S_w| over the replicon's windows in this replicate; NA when undefined —
    observed_max number — Largest observed |S_w| of the replicon required

    • Path: plots/support/null_determinants.tsv

    autocorrelation¶

    Spatial autocorrelation of detection and abundance along each replicon and the origin-to-terminus gradient (GIAP_SPEC.md §9.3, §7.3.5(c) and §7.3.5(e)).

    • Path: —
    • Coordinates: —
    • Schema: tables/autocorrelation.schema.json
    Field Type Unit Description Constraints
    contig string — Replicon name (C1 order) required
    statistic string — Statistic family of the row required; one of morans_i, join_count_bb, oriter_slope
    lag integer — Lag in genes; NA for the descriptive oriter_slope rows minimum 1
    null_model string — Null the row is tested against; bootstrap means a descriptive row with a bootstrap CI and no p-value required; one of gene_label, tu_block, bootstrap
    value number — Reported statistic (Moran's I, the raw BB join count, or the OLS slope in log2 per replichore); NA when it does not exist —
    null_mean number — Mean of the null distribution of the test statistic —
    null_lo number — 2.5th percentile of the null distribution —
    null_hi number — 97.5th percentile of the null distribution —
    stat string — Name of the test statistic of the row required
    effect number — Effect estimate: observed minus null mean, or the OLS slope —
    ci_low number — Lower bound of the 95% confidence interval; NA when unestimated —
    ci_high number — Upper bound of the 95% confidence interval; NA when unestimated —
