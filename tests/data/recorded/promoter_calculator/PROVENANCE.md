# Promoter Calculator 1.2.4 recorded runs (M2-14; GIAP_SPEC.md §7.1.1, §7.1.4)

- Tool: Promoter Calculator 1.2.4 (PyPI `promotercalculator`, GPL; run as a separate process only,
  never imported), `giap-promoter_calculator` micromamba env (`workflow/envs/promoter_calculator.yml`;
  env lock hashes in `sim100k/versions.txt`).
- Recorded by `scripts/slurm/record_tools.sbatch` on FarmShare (sim100k: barley-02, 9 CPUs, 390 s
  wall) into `$GIAP_ROOT/recordings/promoter_calculator/{sim100k,k12_mg1655}/`.
  Command (`command.txt`): `promoter-calculator -i regions/<TU>.fa -o csv/<TU>.csv -j 1`, one region
  per call, 9 calls in parallel.
- Regions: `scripts/dev/record_tools_inputs.py regions <bakta>.json` (distance-model TUs, d ≤ 50 bp
  same strand; upstream −300..+50 around the first start codon, clipped at the nearest gene end /
  start and **linearly** at the contig ends), from the recorded Bakta 1.12.2 full-DB JSONs
  `$GIAP_ROOT/recordings/bakta_full/<sample>/bakta/<sample>.json` (sha256 sim100k
  `d28c87810c2e3feed57c643c8845824b077fe252d8afb250ada86c42a99799cf`, k12_mg1655
  `13c54a8961651053cda596ffa4cc0c611565588112275faf7f3ddc27e28bacec`). The test helper
  `tests/helpers/promoter_calculator_fixtures.py::recorder_tus` rebuilds all 59 sim100k and 2,771
  K-12 regions from those JSONs byte for byte (checked 2026-10-15, test author).
- Full runs: sim100k 59 regions → 59 CSVs (6,449 rows); K-12 MG1655 2,771 regions → 2,751 CSVs
  (238,387 rows). The 20 K-12 regions without a CSV are all 50–75 nt long (shorter than the 83–84 nt
  promoter model, UP..ITR); the tool printed "No promotors found." and wrote nothing
  (PROMOTER_CALCULATOR then writes the 27-column header, M2-07).
- CSV format: 27 columns (`../headers/promoter_calculator.csv.txt`), **CRLF** line ends, rows as
  the tool wrote them. `TSS` convention (Promoter Calculator `wrapper.py`, and checked on every one
  of the 244,836 recorded rows through the `ITR` column): for `+` rows `TSS` is the 0-based index
  of the +1 base in the region (`ITR = region[TSS:TSS+20]`); for `-` rows it is the 1-based forward
  position of the +1 base (`ITR = revcomp(region)[len-TSS:len-TSS+20]`). `PcHit.tss` (1-based)
  is therefore `TSS + 1` for `+` and `TSS` for `-`.

contig_length, topology, strand, tu_start, tu_end` (TU interval, 0-based half-open: `+` starts at
the first start codon, `-` ends after it), `region_start, region_end` (0-based half-open genome
interval of the region; `-` regions are its reverse complement) and `start_codon` (0-based first
